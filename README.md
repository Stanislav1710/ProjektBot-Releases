# PandaOps 3.0.4

created by panda91

[Скачать универсальный установщик для Windows](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.3-preview.6/PandaOpsInstaller.exe) · [Страница загрузки](https://stanislav1710.github.io/ProjektBot-Releases/) · [Все выпуски](https://github.com/Stanislav1710/ProjektBot-Releases/releases)

Установщик загружает актуальные подписанные модули. Для обновления установленного PandaOps откройте вкладку «Обновление» и нажмите «Проверить обновление». Требуется короткий перезапуск.

В 3.0.4 исправлены учёт выхода из Лабиринта по таймеру напарника и отображение полученного здоровья после боя. Оставлена одна настройка лимита воскрешений. В почте можно выделить всё, снять выделение с важных писем и получить выбранное. Для почты и склада доступны отдельные задержки 0,5–5 секунд, по умолчанию 3 секунды; 0,5 секунды не рекомендуется. Добавлены передача прокрутки таблиц на вкладку, проверка ОЦ для игровых локаций и сброс отображаемого счётчика кругов.

Профили и подтверждённый прогресс сохраняются. История установленных версий автоматически ограничена 15 версиями. Реальная игровая приёмка после выпуска проводится отдельно от автоматических проверок.

[Полный подписанный пакет 3.0.4 для поддерживаемого установщика](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.4/PandaOps.pbotupdate).
