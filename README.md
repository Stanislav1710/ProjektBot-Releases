# PandaOps · модульный патч 3.0.4.14

created by panda91

[Универсальный установщик для Windows](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.3-preview.6/PandaOpsInstaller.exe) · [Страница загрузки](https://stanislav1710.github.io/ProjektBot-Releases/)

Исправлены задержки почты и сундуков в отдельном запуске и «Плане на день», сохранение паузы Мимозы и изменение времени ожидания в Лабиринте. Портреты клонов для каталога игры 1.96.1 включены в обычное обновление. Окно CAPTCHA автоматически выходит на передний план; ответ выбирается вручную.

Для обновления: «Обновление» → «Проверить обновление», затем установка с перезапуском. Загружаются изменённые компоненты, прежние проверенные файлы используются повторно. Универсальный установщик получает актуальную компонентную версию.

Полный пакет и legacy-каталоги остаются версией 3.0.4; модульный патч 3.0.4.14 распространяется через компонентные обновления. [Полный подписанный пакет 3.0.4](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.4/PandaOps.pbotupdate).

Профили и подтверждённый прогресс сохраняются. Автоочистка ограничивает историю 15 установленными версиями.
