# PandaOps · модульный патч 3.0.4.22

created by panda91

В Мимозе исправлена обработка пятого этапа полного турнира.

[Универсальный установщик для Windows](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.3-preview.6/PandaOpsInstaller.exe) · [Страница загрузки](https://stanislav1710.github.io/ProjektBot-Releases/)

Добавлены вкладка «Ежедневное», ежедневные действия в новом «Плане на день» и уведомления Telegram. Личный бот подключается без ручного ID: токен → «Подключить Telegram» → «Запустить» в чате. Исправлена остановка ежедневного сбора при отсутствии необязательного времени в ответе сервера.

С версии 3.0.4.3 также улучшены восстановление плана и счётчики, сохранение паузы Мимозы, задержки почты и сундуков. В Лабиринте сохраняется подтверждённый состав, ожидание меняется без повторной оплаты, доступен повтор с тем же напарником в отдельном запуске. Портреты клонов включены в обычное обновление. CAPTCHA автоматически выходит на передний план; ответ выбирается вручную.

Для обновления: «Обновление» → «Проверить обновление», затем установка с перезапуском. Загружаются изменённые компоненты, прежние проверенные файлы используются повторно. Универсальный установщик получает актуальную компонентную версию.

Полный пакет и legacy-каталоги остаются версией 3.0.4; модульный патч 3.0.4.22 распространяется через компонентные обновления. [Полный подписанный пакет 3.0.4](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.4/PandaOps.pbotupdate).

Профили и подтверждённый прогресс сохраняются. Автоочистка ограничивает историю 15 установленными версиями.
