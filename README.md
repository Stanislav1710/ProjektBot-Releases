# PandaOps · модульный патч 3.0.4.11

created by panda91

[Универсальный установщик для Windows](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.3-preview.6/PandaOpsInstaller.exe) · [Страница загрузки](https://stanislav1710.github.io/ProjektBot-Releases/)

Патч 3.0.4.11 исправляет номер телефона получателя Сбера: +7 911 074 47 45. Включены накопительные улучшения «Плана на день» и отдельные пакеты изображений/шрифта интерфейса. При первом обновлении с 3.0.4.4 будут загружены изменённые компоненты и четыре пакета ресурсов; последующие обновления смогут переиспользовать эти ресурсы.

Для модульного клиента: «Обновление» → «Проверить обновление». Загружаются изменённые компоненты, установка требует короткого перезапуска. Универсальный установщик получает актуальную компонентную версию.

Отдельный полный пакет и legacy-каталоги остаются версией 3.0.4; полного пакета 3.0.4.11 нет. [Полный подписанный пакет 3.0.4](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.4/PandaOps.pbotupdate).

Профили и подтверждённый прогресс сохраняются. Автоочистка ограничивает историю 15 установленными версиями. Публикуются клиентские выпуски и подписанные обновления; исходники и инструменты администратора не публикуются.
