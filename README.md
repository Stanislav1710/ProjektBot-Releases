# PandaOps · модульный патч 3.0.4.12

created by panda91

[Универсальный установщик для Windows](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.3-preview.6/PandaOpsInstaller.exe) · [Страница загрузки](https://stanislav1710.github.io/ProjektBot-Releases/)

В Лабиринте добавлена настройка повторов с тем же напарником при выключенном «Плане на день»: после завершения прохода бот ждёт его приглашение до 10 секунд и принимает раннее приглашение сразу. Задержки получения наград почты и склада от 0,5 до 5 секунд теперь работают и в «Плане на день». Обновлены иконки приложения и окон.

Для обновления: «Обновление» → «Проверить обновление», затем установка с перезапуском. Загружаются изменённые компоненты, прежние проверенные файлы используются повторно. Универсальный установщик получает актуальную компонентную версию.

Полный пакет и legacy-каталоги остаются версией 3.0.4; модульный патч 3.0.4.12 распространяется через компонентные обновления. [Полный подписанный пакет 3.0.4](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.4/PandaOps.pbotupdate).

Профили и подтверждённый прогресс сохраняются. Автоочистка ограничивает историю 15 установленными версиями.
