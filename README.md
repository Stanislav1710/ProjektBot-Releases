# PandaOps · модульный патч 3.0.4.4

created by panda91

[Универсальный установщик для Windows](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.3-preview.6/PandaOpsInstaller.exe) · [Страница загрузки](https://stanislav1710.github.io/ProjektBot-Releases/)

Патч 3.0.4.4 исправляет преждевременную остановку Лабиринта в дневном плане при повторном подборе состава. Уже полученный и подтверждённый состав той же комнаты сохраняется после свежей проверки готовности. Подтверждённая история, неопределённые расходы и ручной Stop сохраняются. Обновляется только Core: около 1,5 МБ с 3.0.4.3, остальные 15 компонентов переиспользуются.

Для модульного клиента: «Обновление» → «Проверить обновление». Загружаются изменённые компоненты, установка требует короткого перезапуска. Универсальный установщик получает актуальную компонентную версию.

Отдельный полный пакет и legacy-каталоги остаются версией 3.0.4; полного пакета 3.0.4.4 нет. [Полный подписанный пакет 3.0.4](https://github.com/Stanislav1710/ProjektBot-Releases/releases/download/v3.0.4/PandaOps.pbotupdate).

Профили и подтверждённый прогресс сохраняются. Автоочистка ограничивает историю 15 установленными версиями. Публикуются клиентские выпуски и подписанные обновления; исходники и инструменты администратора не публикуются.
